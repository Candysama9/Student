# 成都高一物理 · 家校沟通话术总库（在线版）

## 文件说明
- `index.html` - 主页面（话术手册）
- `data.json` - 话术数据文件

## 部署方法

### 方法一：Netlify（推荐，最简单）
1. 访问 https://app.netlify.com/drop
2. 将整个 `online-version` 文件夹拖入页面
3. 获得一个在线链接，即可分享给老师

### 方法二：GitHub Pages
1. 在 GitHub 创建一个新仓库
2. 上传 `index.html` 和 `data.json` 两个文件
3. 在仓库设置 → Pages 中开启 GitHub Pages
4. 选择 main 分支即可获得在线链接

### 方法三：本地使用
直接用浏览器打开 `index.html` 即可（需确保 `data.json` 在同一目录）

## 维护说明

### 在线编辑
1. 打开页面后，点击右下角的 ⚙ 按钮
2. 点击"开启编辑"进入编辑模式
3. 直接在文本框中修改话术内容
4. 修改后点击"保存此条"或退出编辑模式自动保存
5. 点击"导出数据"可下载最新的 data.json 文件

### 更新线上数据
1. 在编辑模式中修改内容
2. 点击"导出数据"下载新的 data.json
3. 用新的 data.json 替换服务器上的旧文件

### 占位符说明
话术中的 `#沟通称呼语#` `#学员昵称#` `#性别代词(他/她)#` 为群发助手自动替换词，
复制时无需修改，发送时系统会自动匹配对应学员信息。
